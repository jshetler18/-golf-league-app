v13.82 - Past Scorecard Team Dropdown Fix

- Upload a Past Scorecard now asks for League Month before Team.
- Team dropdown is disabled until a month is selected.
- Team dropdown only loads teams whose season_id matches the selected league month's season_id.
- This removes duplicate-looking team names from other seasons while preserving historical uploads.
- No database changes.

Head-to-head shared scorecard note:
For a Week 4 matchup where both teams are on one physical scorecard, upload the image only once under either matchup team. Recorded Rounds matches a head-to-head video against both team names, so the single approved scorecard will appear with that matchup video. Do not upload the same shared image twice.
