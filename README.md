# Golf League App v9.6

Changes from v9.5:
- Booking success now plays a short confirmation chime after a reservation is saved.
- No time is preselected when opening a fresh day; all available slots remain green until the player explicitly taps/clicks a slot or chooses a start time from the dropdown.
- Changing the date clears any previous time selection.
- Selected available slots remain orange until confirmation; confirmed reservations refresh as unavailable/red.
- Includes all v9.5 booking, My Bookings, trophy, league, and admin changes.
