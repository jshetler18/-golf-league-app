v13.29 - Rules & Settings

Player-facing changes:
- Home screen "Rules" button renamed to "Rules & Settings".
- Rules & Settings page now has two tabs:
  1. Rules — keeps the existing admin-managed League Rules content unchanged.
  2. Monthly Settings — lets players choose each configured league month and see that month's setup.
- Monthly Settings displays:
  * Course name
  * League holes 1-10
  * Two bonus par-3 holes
  * Elevation
  * Stimp options
  * Gimmie distance
  * Wind
  * Greens
  * Fairways
  * Mulligans
  * Week 1, 2, 3, and 4 pin settings
  * Tee box colors and yardages
  * Every player's monthly tee assignment, team, tee color/name, and yardage
- Settings are read directly from the existing Admin Monthly League Setup data, so player-facing information updates when the admin saves a month's setup.
- Only configured/saved months are shown.
- No database changes.
