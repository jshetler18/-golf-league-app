v13.100 - RSVP roster edit synchronization

- Open RSVP meetings now synchronize existing invitee snapshot names and teams with the active league roster.
- Renaming/replacing a roster slot (for example Player 4 -> Rich Voytko) updates the RSVP page automatically.
- Moving an existing player to another team updates the RSVP team grouping automatically.
- Existing RSVP response status and responded_at values are preserved.
- New active players continue to be added automatically.
- Closed meetings remain frozen for historical accuracy.
- No database migration required.
