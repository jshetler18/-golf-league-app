v13.107 - Handicap Reset + Rounded Average Detail

- Adds a month-specific Reset Handicaps button to the admin monthly handicap workflow.
- Reset clears saved monthly handicap selections and any published snapshot for that month only.
- Reset does not change historical raw scores or the handicap calculation history.
- After reset, current calculated recommendations are loaded again so the admin can start over.
- Published months show a stronger Reset Published [Month] Handicaps confirmation warning.
- On Teams & Handicaps > Handicaps, expanded team details now show the precise Handicap Raw Scoring Average and, beside it, "Rounded To:" with the whole-number value used to determine the monthly handicap.
