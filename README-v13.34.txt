v13.34 - Tee assignment ball-speed guideline table

Added a player-facing table inside the Tee Assignments rule section:
- Forward / Turquoise: under 105 mph; under ~170 yd carry; 4,200–4,800 yd
- Senior / Red: 105–119.9 mph; ~170–195 yd; 4,800–5,300 yd
- Middle / Yellow: 120–134.9 mph; ~195–220 yd; 5,300–5,800 yd
- Back / Blue: 135–149.9 mph; ~220–245 yd; 5,800–6,300 yd
- Tips / Black: 150+ mph; ~245+ yd; 6,300–6,800+ yd

The table is automatically displayed beneath any Rules section whose heading contains "Tee Assignment".
It also explains that driver ball speed is the primary guideline and that the admin can adjust assignments based on typical carry/course length.
No database changes.
